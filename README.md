# 九州ふっこう応援割 発車標

九州7県（福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島）の「九州ふっこう応援割」について、
**各県の予約開始日・割引対象期間・県議会の補正予算・OTAの販売状況**を1日4回
（日本時間 8:00 / 12:00 / 17:00 / 20:00）自動でウォッチし、このページを更新しています。

- ページ: <https://endodo.github.io/kyushu-ouenwari/>
- データ: [`data.json`](data.json) — 更新はすべてここへのコミットとして残ります

## 情報源の扱い

- **一次**: 各県の観光担当課の報道発表、および OTA（楽天トラベル・じゃらん・JTB 等）の販売開始
- **追認**: 観光庁の[集約ページ](https://www.mlit.go.jp/kankocho/page13_00002.html)
  — 県別表は各県の発表から1日以上遅れることがあります
- 公式ドメイン外を根拠にした値には ［参考］ を付けています

予約可否・条件は必ず各県の公式発表と予約サイトで確認してください。

```json
      "確度": { "予約開始": "公式", "議会": "参考" }
    }
  },
  "history": [
    { "at": "ISO8601", "changes": [
      { "pref": "熊本", "field": "予約開始", "from": "未公表", "to": "9/26 10:00",

  ]
}
```

`確度` が `"公式"` 以外のフィールドは、ページ上で ［参考］ と表示されます。

## 宿の料金監視（`watch/hotel.py`）

1軒の宿について、指定日・指定人数の料金を予約サイト横断で取り、Slack に流します。
いまの対象は **アイランド長崎（i+Land nagasaki）2026/12/6〜1泊・大人2名**。

- 取得先: 公式HP（489ban）・じゃらん・楽天トラベル（一休・Yahoo!トラベルは Actions からも 403 のため対象外）
- 30分に1回取得し、食事タイプ別（朝食付・2食付など）に「実質」最安を比べる。
  実質＝合計料金 − クーポン − 付与ポイント
- 即時通知（メンション付き）: 実質最安が過去最安より1,000円以上下がった／同じプランが前回より10%以上値下がり／
  セール・割引のプランが新しく出た／新しいクーポンが出た
- 毎朝8時台の現状まとめに、サイト別・食事タイプ別の最安を添える。チェックイン日になったら止まる

対象の宿・日付・人数は `watch/hotel.py` の `HOTEL` で変えられます。
